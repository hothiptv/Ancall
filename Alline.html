Trực thuộc: Tập đoàn Hothiptv / AllineCs

AllineCs là một thư viện Front-end độc quyền được sáng lập và phát triển bởi lập trình viên Nguyễn Trọng An.

Sứ mệnh của AllineCs là cung cấp một kiến trúc nhúng gọn nhẹ, giúp các dự án web tự động đồng bộ hóa hình nền (backgrounds) và thông tin tác giả trực tiếp từ máy chủ lưu trữ đám mây (Firebase Cloud). Mọi thao tác cập nhật giao diện web giờ đây có thể được quản lý hoàn toàn từ xa mà không cần can thiệp vào mã nguồn nội bộ.

2. Cài đặt Thư viện (CDN)

Để tích hợp AllineCs vào dự án của bạn, hãy sao chép và dán 2 đường dẫn CDN dưới đây vào file index.html. Lưu ý: Bạn không cần tải file về máy, hệ thống CDN toàn cầu sẽ đảm bảo tốc độ phản hồi tính bằng mili-giây.

File Định dạng (CSS)

Đặt thẻ này vào bên trong cặp thẻ <head> của bạn.

<!-- AllineCs Core CSS --> <link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/hothiptv/AllineCs@main/alline.css">
File Xử lý Logic (JavaScript)

Đặt thẻ này ở ngay trước thẻ đóng </body> để đảm bảo hiệu suất tải trang.

<!-- AllineCs Core JS & Firebase Sync --> <script src="https://cdn.jsdelivr.net/gh/hothiptv/AllineCs@main/alline.js"></script>

3. Hướng dẫn Khai báo Body

Sau khi nhúng thành công 2 file CDN ở trên, bước cuối cùng là bạn phải "báo" cho thư viện biết trang web này muốn sử dụng hình nền nào. Điều này được thực hiện thông qua việc gắn Class vào thẻ <body>.

Cú pháp chuẩn: <body class="[tên_class_nền]">

Ví dụ thực tế:

Nếu trong thư viện cơ sở dữ liệu của bạn có một nền mang mã khóa (Class) là abgeo, bạn sẽ viết HTML như sau:

<!DOCTYPE html> <html lang="vi"> <head> <title>Trang chủ của tôi</title> <!-- Đã nhúng alline.css ở đây --> </head> <!-- Khai báo Class nền tại đây --> <body class="abgeo"> <h1>Nội dung trang web...</h1> <!-- Đã nhúng alline.js ở đây --> </body> </html>

Mẹo: Bạn có thể xem danh sách các Class hợp lệ ở phần Thư viện Thông tin Nền bên dưới.
